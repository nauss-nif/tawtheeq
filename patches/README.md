# تصحيحات الحزم (patch-package)

تُطبَّق تلقائيًا بعد `npm install` (سكربت `postinstall`).

- `@react-pdf+textkit+4.4.1.patch`: كانت المكتبة تُسقط «لا» المتكررة في السطر الواحد من ملفات الـPDF
  (تقارن الـligature برقم الرسم)، فصارت المقارنة بموضع الرسم داخل السطر، مع حماية من موضع بلا رسم.

**مهم عند تعديل أي تصحيح:** خوادم Vercel تحتفظ بـ`node_modules` مُصحّحة من النشر السابق،
فيفشل تطبيق التصحيح الجديد فوق القديم ويتوقف النشر بخطأ `npm install exited with 1`.
انشر مرة واحدة دون ذاكرة البناء:

```bash
vercel --prod --force
```
